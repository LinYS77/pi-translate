# v0.3.0

- Translate the user's task instructions into English while preserving original task material for the main model. Recognize introduced passages, quoted material and inline task objects; keep uncertain material conservatively and merge compatible instruction fragments to reduce requests.
- Limit Jev to ambiguous input roles and output language judgments. Clear English prose stays on the local route. Pack complete classifier requests against model capacity instead of skipping an oversized batch. Jev now falls back silently; confidence thresholds remain unchanged.
- Raise per-operation limits from 64 to **2,048 requests** and from 131,072 to **4,194,304 tokens**. Settle completed requests against actual usage or conservative estimates rather than repeatedly charging unused output allowances. Budget errors now identify the exhausted limit.
- Add **Ctrl+Alt+T** to restore the latest available original input into an empty editor. It never overwrites a draft, submits a task or changes the translation switch. The recovery menu remains available if the terminal or OS intercepts the shortcut.
- Show all settings when the panel has room; scroll only in smaller windows without resetting selection. Remove duplicate translation diagnostics.

## Upgrade notes

Existing model selections, timeouts and startup preferences are preserved; no configuration migration is needed. The higher budgets can allow more work and cost, but do not extend the saved total timeout or the model's per-request limits. Actual translation failures and partial output remain visible, and original answers remain intact.

Local rules remain the default. Role detection and mixed-language handling are heuristic; Jev can still be uncertain, and the unchanged confidence gates are not calibrated accuracy guarantees. This release does not claim general semantic accuracy improvements.

Pi 0.99.2+ and Node.js 22.19+ remain supported. Verification includes 141 automated tests, package loading, and CI for Pi 0.99.2 / 1.0.0 on Node 22.19 / 24.

**GitHub release only for now. npm publication is separate and has not been performed by this release workflow.**
