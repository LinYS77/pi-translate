# v0.2.0

- Configure translation timeout directly in `/translate`, with presets and exact custom seconds. Existing saved values are preserved.
- Choose local rules or an independent Jev classifier in the same settings overlay. Jev uses Pi's existing credentials and visibly falls back to local rules when unavailable or uncertain.
- Keep code blocks and unchanged paragraphs local; translate selected source ranges instead of asking a model to copy a whole masked document.
- Improve mixed Chinese/English term handling and short-warning detection. Ordinary quoted prose can be translated while literal labels remain protected.
- Repair a damaged fragment at most once. Input still requires complete success before submission; output may preserve failed fragments in place with an explicit partial-translation warning.
- Share one deadline and bounded request budget across classification, translation and repair. Cancellation discards pending output and never starts a fallback request.

Pi 0.99.2+ and Node.js 22.19+ remain supported. CI checks Pi 0.99.2 and 1.0.0, including automated regression tests and actual tarball loading.

Local rules remain the default. Jev does not generate translations; its documented CJK limitations still apply. New configuration fields must be removed (or a backup restored) before downgrading to v0.1.x.

GitHub release and npm publication are separate. The maintainer publishes this exact tagged commit to npm; CI does not publish it.
