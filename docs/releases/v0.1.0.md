Initial public release of **[@linys77/pi-translate](https://www.npmjs.com/package/@linys77/pi-translate/v/0.1.0)**.

## Highlights

- Submit Chinese prompts in Pi; translate them to English without rewriting the conversation history.
- Read a Chinese translation of the true final answer, not intermediate messages, thinking or tool output. Original answers stay intact; displayed translations are excluded from model context.
- Configure an independent translation model once, without switching the main model.
- Toggle with **Alt+T** and configure with the single **`/translate`** command. Settings and model search share one Pi-managed overlay.
- Preserve recognized code, paths, identifiers, numbers and quoted literals. English inputs and already-Chinese outputs bypass unnecessary translation.
- Input translation failures block submission and retain the original for explicit recovery. Output failures leave the completed task untouched.

## Install

```bash
pi install npm:@linys77/pi-translate
```

Restart Pi or run `/reload`, then open `/translate` to select a translation model. Remove another Git/local installation of this extension before switching to npm.

Requires **Pi 0.99.2+** and **Node.js 22.19+**, in TUI mode. Also verified with Pi **1.0.0** on Node 22.19.0 and 24. Translation accuracy still depends on the provider and model you choose.
